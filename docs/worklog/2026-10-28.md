## 출시 준비 재검증·보행 근거 출처 보강

- 운영 프런트 빌드 통과. 기본 Playwright 실행은 설치된 chromium_headless_shell 부재로19개 모두 브라우저 시작 전에 실패했다. README의 기존 PLAYWRIGHT_CHANNEL=chrome 설정으로 재실행하여 UI19/19 및 브라우저→Worker→SQL/PWA 통합2/2 통과했다. 설치·제품 코드 변경으로 우회하지 않았다. 고정 공급자 응답을 사용한 로컬 검사이며 실제 경로·원격 운영·Android 실기기 통과가 아니다.
- npm run release:check는 종료코드1, RELEASE BLOCKED를 반환했다. 기본 실행 환경에서 검수 카탈로그/수량, 실제 운영자·도메인·Android 패키지/서명, 경로 승인/근거, assetlinks, APK/AAB, TWA 설정, Android 관측 근거가 충족되지 않았다. 로컬 비밀 설정 파일을 자동 로드하지 않는 명령의 결과이며 원격 설정 존재 여부를 증명하지 않는다.
- [거점 검수 보고](../HUB-REVIEW.md)에 공식 보행 자료3종의 기준일과 구자료 대체 경로를 추가했다. 엘리베이터 좌표의 일일 갱신일과2020년 조사 기준을 구분하고, 설치현황은2026-09-01, 역이용안내도 최신 파일 목록은2026-08-24임을 확인했다. 원문행·도면 전체 대조나 현장 확인은 미실행, 승인0개 유지. 링크의 공식 설명을 대조했으며 새 원본을 카탈로그에 합치지 않았다.
