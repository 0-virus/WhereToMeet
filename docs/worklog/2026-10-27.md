- 테스트 `tests/finish-work-hook.test.mjs`: 깨끗한 저장소, 미커밋 파일, 미푸시 커밋, 재개/계획/중단 이벤트, Git 확인 실패의 5개 검사 통과. 실패 테스트를 먼저 실행한 뒤 구현했다.
- 전체 자동 테스트 97/97 및 `git diff --check` 통과. 등록한 Windows 명령에 Stop 입력을 직접 전달하여 JSON 재개 응답을 확인했다. 훅 JSON은 BOM 없는 UTF-8로 저장했다. UI·실제 API 검증은 이번 훅 변경에서 재실행하지 않았다.
- [공식 훅 문서](https://learn.chatgpt.com/docs/hooks)에 따라 프로젝트 및 새 훅 정의의 신뢰가 필요하다. 사용자 다음 작업은 Codex `/hooks`에서 해당 훅을 검토·신뢰하는 것이다. 이 세션에서 실제 Stop 이벤트 자동 실행은 확인하지 않았으며, 신뢰 설정을 대신 변경하지 않았다. 활성화 전에도 에이전트는 AGENTS.md 완료 절차를 따른다.
