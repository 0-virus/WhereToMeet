# 2026-10-23 작업 기록

공급자 공식 문서 조사 기록을 2026-10-27에 이관했다. 실제 API 호출 결과는 [10월 27일 기록](2026-10-27.md)을 참고한다.

### 2026-10-23 공급자 준비 현황

- 사용자는 Kakao·TravelTime 키를 준비했다고 알렸다. Kakao 무료 쿼터는 월 3,000,000건, 일 REST API 100,000건 또는 SDK 300,000건으로 사용자 전달 내용이며, 이번 조사에서 계정별 적용 여부는 확인하지 않았다. TravelTime 계정은 trial로 전달받았으며 가입일·개별 한도·만료일은 미확인이다.
- [TravelTime 사용량 제한](https://docs.traveltime.com/api/overview/usage-limits)과 [가격 안내](https://traveltime.com/pricing)는 Basic 무료 키를 120 HPM, 일반 Isochrone·Matrix 최대 이동시간 4시간, 등시간권 상세도 최대 Medium(0)으로 안내한다. HTTP 요청 수와 hit 수는 다르며 Matrix 검색 하나가 1 hit다. 이를 개별 trial 계정의 확정 한도로 자동 설정하지 않았다.
- [약관 12.2~12.6](https://traveltime.com/terms-of-service)은 trial을 가입일부터 최대 14일(별도 서면 합의 가능), 종료 후 Non-Paid 서비스 전환으로 설명한다. Trial·Non-Paid는 별도 합의 없이는 내부 평가용이며 최종 사용자 제공·상업 이용이 허용되지 않는다. [2026-09-17 라이선스 안내](https://help.traveltime.com/en/articles/9685030-licence-options)는 개발·통합 테스트 무료 접근을 안내한다. 무료 접근과 trial 기간을 구분하고 계정 적용 조건을 확인해야 한다.
- [지원 국가](https://docs.traveltime.com/api/overview/supported-countries)는 한국 대중교통 Full(알려진 정류장 95% 이상), 자동차·도보·자전거 None으로 표시한다. 한국은 Fast 지원 목록에 없다. 대중교통 내 도보 연결, 수도권 노선별 누락과 정확도까지 입증한 것은 아니다.
- [공통 개념](https://docs.traveltime.com/api/overview/key-concepts)은 일반 API의 출발·도착 검색 및 통상 현재 날짜 전후 2주 시간표를 설명한다. 7일 이내 약속은 일반적인 문서 범위 안이지만 한국의 실제 날짜별 데이터는 미검증이다. [Matrix 명세](https://docs.traveltime.com/api/reference/travel-time-distance-matrix)는 다대일 도착 검색·요청당 최대 10검색·route 속성을 제공한다. 도착 검색 설명의 “no earlier than”과 [도움말의 가장 늦은 출발 설명](https://help.traveltime.com/en/articles/8523982-how-do-the-models-determine-which-route-to-take) 간 불일치는 남아 있다.
- 이번 결과는 공식 문서 조사이며 API 호출·과금·배포·실기기 검증을 수행하지 않았다. 기존 10월 14일 테스트 결과의 날짜와 판정은 유지한다. 다음 사용자 확인은 계정의 trial 시작일·적용 HPM·무료 범위 내 검증 방침이며, 다음 에이전트 작업은 준비 조건 확인 후 소량 실제 응답으로 도보 연결·7일 이내 날짜·도착시각·교통수단 범위를 검증하는 것이다.
