- [표본 결과](../data/review-evidence/sample-2026-10-28.json): 100요청·100건 HTTP 200. [전체 결과](../data/review-evidence/preview-2026-10-28.json): 같은 fingerprint의 당일 100개 결과 재사용 + 추가 500요청·500건 HTTP 200. 합계 **600요청**, 재시도·거부 0건. TravelTime 호출은 없다.
- API는 순차 호출하고 호출 사이 100ms 대기, 요청별 15초 제한과 첫 오류 중단 조건을 적용했다. 서버 키는 로컬 설정에서 읽고 출력·저장하지 않았다. 공개 교통 거점의 ID·이름·법정동 코드/지역명·시각·fingerprint만 기록했다.
- 결과 파일의 각 행은 원본 일치, 지역 대조, 대표점, 보행 접근성, 출시 적격 상태를 구분한다. fingerprint는 기존 reviewFingerprint를 사용하며 지점 정보가 바뀌면 재사용할 수 없다. 두 결과 파일의 중복 행을 추가 조회 횟수로 합산하지 않는다.
