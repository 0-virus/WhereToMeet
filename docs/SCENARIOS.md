## 재현 근거

- `npm test`: 카탈로그, 추천 엔진/공급자 어댑터, 검증 CLI, API, 실제 SQLite SQL, 동시성, PWA 보안 검사.
- `npm run test:e2e`: 외부/API 응답을 대체한 Chrome 앱 시나리오. `tests/e2e/app.spec.ts`에 기대값 기록.
- `npm run test:fullstack`: 빌드된 앱 + 실제 Worker 핸들러 + SQLite에서 기록/권한/삭제와 실제 서비스 워커 검증. 공급자와 경로 결과만 테스트용.
- 로컬 Wrangler: 실제 D1 마이그레이션과 정적 파일·API 스모크 검사. 원격 D1 또는 배포된 HTTPS 검증이 아님.
- 상세 실행 결과와 잔여 조건: [검증결과.md](검증결과.md).

## 외부 준비

TravelTime/Kakao 키, 공급자 사용권·실제 한도, 검수된 카탈로그, Cloudflare 계정, 도메인·패키지 ID·서명, Android/iOS/Samsung Internet 접근, 실제 이동 관측, 운영 연락처가 필요합니다.
미충족 항목이 있으면 배포 준비 완료로 판정하지 않습니다.
