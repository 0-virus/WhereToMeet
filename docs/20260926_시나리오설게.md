┌─ 접속
├─ 만나는 사람 인원수 선택 (2~4명)
│   ├─ 인원수만큼의 주소 검색창 표시
│   ├─ 각자의 출발지 주소 입력
│   ├─ 검색 → 히스토리에 저장
│   ├─ 검색 결과 유효 후보지 최대 4개 생성 (부족하면 실제 개수만 표시)
│   │ └─ 북마크 → 히스토리 상단 고정
│   ├─ 각 후보지 선택 시 주변 식당·카페·놀거리 등 리스트업(탭으로 표시)
│   └─ 장소 선택 → 지도 앱으로 연결(네이버지도 등 API)
└─ 북마크 & 히스토리 선택
    └─ 검색 기록 리스트 표시, 북마크된 기록은 상단 고정
    └─ 기록 열람 시: 매번 새로 검색. 원래 약속이 지났으면 출발지를 복원하고 새 약속 시각 선택

승인된 추가 조건: 서버 익명 저장, 일반 기록은 마지막 검색일부터 90일, 북마크 기록은 삭제 전까지 유지. 개별·전체 삭제 제공. 상세 기준: [IMPLEMENTATION.md](./IMPLEMENTATION.md).
