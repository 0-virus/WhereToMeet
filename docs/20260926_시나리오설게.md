│   ├─ 인원수만큼의 주소 검색창 표시
│   ├─ 각자의 출발지 주소 입력
│   ├─ 검색 → 히스토리에 저장
│   ├─ 검색 결과 후보지 2~4개 생성

    └─ 기록 열람 시: < 7일 → 이전 기록 사용, > 7일 → 새로 검색(최신 결과 반영)
